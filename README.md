## What It Does

Every platform re-encodes your videos. Masterbay gives them a clean, high-bitrate file that matches their encoder expectations.

**Drop in any video → Get detailed analysis → Choose target → Adjust settings → Download mastered file.**

## Download

Get the latest build from **[Releases](https://github.com/youcefesseid/masterbay/releases)**:
- **Masterbay-Setup-1.0.0-win-x64.exe** — NSIS installer (desktop/start-menu shortcuts)
- **Masterbay-Portable-1.0.0-win-x64.exe** — Portable (no admin, runs anywhere)

> **Note on SmartScreen:** The binaries are unsigned (no paid code-signing certificate). Windows may show a warning on first run. Click "More info" → "Run anyway". A false-positive submission has been filed with Microsoft.

## Quick Start (Electron App)

1. Download `Masterbay-Setup-1.0.0-win-x64.exe` (or the Portable)
2. Run it → Click "More info" → "Run anyway" if SmartScreen appears
3. Enter your license key + email → Click "Activate"
4. The app opens at `http://127.0.0.1:4173`

### Developer Mode (from source)
```bash
npm install
npm start
# Open http://127.0.0.1:4173
```

## License Activation

1. Launch Masterbay
2. Enter your license key (format: `MB-xxxx-xxxx-xxxx-xxxx`)
3. Enter your email
4. Click "Activate"

License keys are generated by the author via `scripts/generate-license.js` and verified by the Cloudflare Worker at `masterbay-license.youcefesseid07.workers.dev`.

## Development

### Project Structure
```
masterbay/
├── server.js          # Entry point (HTTP server + API)
├── src/               # Server logic, license, anti-tamper, pipeline
├── public/            # Frontend (HTML/CSS/JS, RTL-aware)
├── electron/          # Electron packaging (main.js, preload.js)
├── scripts/           # Build, license generator, e2e tests
├── bin/               # FFmpeg binaries (placed at build time)
├── docs/              # Roadmap + IP protection
└── wrangler.toml      # Cloudflare Worker config
```

### Scripts
```bash
npm start              # Start server
npm run dev            # Start with auto-reload
npm run check          # UI validation
npm run e2e            # End-to-end tests
npm run doctor         # System check
npm run electron:build # Build NSIS installer
npm run electron:build:portable  # Build portable exe
```

### Deploy License Worker
```bash
cd src
wrangler deploy
```
